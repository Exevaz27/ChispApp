# ⚡ ChispApp - Preparador Técnico de Seguridad Eléctrica BT/MT

¡Bienvenido a **ChispApp**! La plataforma interactiva diseñada para la preparación integral del examen técnico de ingreso laboral para linieros y técnicos de redes de distribución de Baja y Media Tensión.

🌐 **Sitio Web en Vivo:** [https://ChispApp.github.io/](https://ChispApp.github.io/)

---

## 🌟 Características Principales

* 📖 **Modo Estudio y Flashcards:** 32 preguntas técnicas clave con puntos destacados y respuestas oficiales.
* 🎧 **Reproductor Continuo de Audio ("Escuchar Todo"):** Lectura secuencial en voz alta con selector de velocidad ($1.0\times, 1.25\times, 1.5\times$) y seguimiento visual.
* 📝 **Simulacro Real con Temporizador (15 Minutos):** Examen formal con cuenta regresiva, ficha diagnóstica por categorías y revisión pregunta por pregunta.
* 🧩 **Desafíos de Ordenamiento:** Secuencias obligatorias (5 Reglas de Oro, Cambio de Fusibles NH, Transformador mochilero, RCP).
* 🎮 **Minijuegos:** Match de magnitudes y distancias, test rápido de Verdadero/Falso y calculadora de empotramiento de postes.
* 🪵 **Simulador de Campo:** Inspección reglamentaria de 4 pasos para postes de madera.
* 🔌 **Simulador de Voltímetro en Toma BT:** Mediciones $220\text{V}$, $380\text{V}$ y $0\text{V}$.
* 📚 **Diccionario de Siglas:** Buscador de términos técnicos (*SIT, ARPO, T4, SRT, EPP, EPC, etc.*).
* 📱 **PWA Compatible:** Instalable en teléfonos móviles como aplicación nativa.
